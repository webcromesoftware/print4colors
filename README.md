# Print4Colors — Commercial Online Printing Platform

**Print4Colors** provides direct, factory-scale commercial print ordering and instant dynamic pricing across the USA without requiring a trade-only reseller account.

---

## 🚀 Key Features

- **Product Configurator & Instant Pricing Engine:**
  - Real-time price matrix calculation based on size, stock, sides, coating, quantity, and turnaround (24h Rush vs. Standard).
  - Preflight artwork upload validator with PDF/PNG/JPG client-side checking (dimensions, DPI check, trim & bleed warning, color mode alert).
- **Template Customizer:**
  - Live in-browser editing for Business Cards, Flyers, and Brochures with trim/safety guide overlays, front & back view switcher, and instant high-res proof export.
- **Interactive Proof Approval & Versioning:**
  - Digital proof viewer with zoom & pan, side-by-side comparison, revision history notes, and 1-click Approve or Request Changes.
- **Admin Management Panel:**
  - Total sales, revenue, orders counter, pending proofs & artwork queue.
  - Complete 11-step commercial order workflow tracker (Order Placed -> In Production -> Shipped -> Delivered).
  - Carrier tracking number entry (FedEx / UPS / USPS) and proof upload for revision cycles.
- **Customer Account Portal:**
  - Order history, digital proof sign-off center, re-order capability, shipping addresses, and invoice downloads.
- **Multi-Item Shopping Cart & US Regional Checkout:**
  - Zip code tax calculation, shipping rate estimation (FedEx Ground, Overnight, 2-Day Air), and payment processing.

---

## 🛠 Tech Stack

- **Framework:** React 19 + TypeScript + Vite 8
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Animations:** Motion

## 💻 Getting Started Locally

```bash
# Clone your repository
git clone https://github.com/<your-username>/<your-repo-name>.git

# Navigate into the project directory
cd <your-repo-name>

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
